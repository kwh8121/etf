# ETF 추천 연구 데이터 확보 가능성 조사 (ER-1)

> 조사일: 2026-10-23 KST. 대상: [추천 계획 v0.3](../plans/2026-10-23-etf-market-outperformance-recommendation-draft.md)의 5절 데이터 계약과 G1.
> 방법: 운영 DB 읽기 전용 집계 조회(값·비밀 미출력), KRX ETF 일별매매정보 API 읽기 전용 GET 탐침(기존 `KRX_API_KEY`, 응답 원문 미저장), 공개 문서 검색. 쓰기·신규 가입·자격 증명 변경은 하지 않았다.

## 결론

**G1은 현재 통과하지 못한다.** 가격·거래대금·개장가·당시 종목군은 KRX ETF API 백필로 확보할 수 있는 근거가 확인됐다. 반면 총수익 계산에 필요한 분배금 이력, KOSPI 200 총수익지수, 당시 유형·섹터 분류는 현재 원천으로 확보되지 않았다. 따라서 정식 성과 게이트(G3)의 근거는 만들 수 없고, 분배금을 반영하지 않는 **가격수익률 기반 예비 연구**까지만 가능하다.

## 1. 운영 DB 보유 범위 (읽기 전용 집계)

| 항목 | 실측 | 판정 |

| `etf_daily_kr` | 52,639행, 45거래일, 일 1,161~1,183종목, 고유 코드 1,191 | 274거래일 준비 구간의 약 16% |

결론: 운영 DB만으로는 8.1절 구간(준비 273일 + 개발 24개월 + 평가 36개월)을 충족할 수 없다. 운영 DB에 장기 이력을 쓰는 방식은 승인 대상이므로 쓰지 않고, 필요하면 로컬 연구 산출물로 분리한다.

## 2. KRX ETF 일별매매정보 API의 과거 제공 범위 (탐침)

`etp/etf_bydd_trd?basDd=…`를 대표일에 1회씩 호출했다. 모든 날짜에서 HTTP 200이었고 종가·개장가가 전 행 존재했다.

| 기준일 | 행 수 | 기준일 | 행 수 |
| --- | --- | --- | --- |
| 2010-01-04 | 50 | 2021-01-04 | 468 |
| 2015-01-02 | 172 | 2022-01-03 | 533 |
| 2019-01-02 | 413 | 2023-01-02 | 666 |
| 2020-01-02 | 450 | 2024-01-02 / 2025-01-02 / 2026-01-02 | 812 / 935 / 1,058 |

- 행 수가 시점에 따라 증가하므로 날짜별 응답이 **그 시점의 상장 종목**을 반영하는 것으로 보인다. 2022-01-03 응답 533종목 중 67개가 2026-09-22 응답에 없고, 폐지 추정 종목(예: `ARIRANG 200동일가중`)이 과거 응답에 포함됐다. 생존편향을 줄일 근거이며, 코드 변경·합병·명칭 변경을 폐지와 구분하는 검증은 ER-2 전에 필요하다.
- 따라서 7년 이상(2019~) 가격·거래대금·개장가 백필은 기술적으로 가능해 보인다. 2019년 이전은 종목 수가 적어 표본 대표성이 낮다.
- **미확인:** 가격이 분할·병합 등으로 소급 조정되는지, 응답이 당시 값인지 후일 정정값인지(`available_at` 재현), 호출 횟수 한도. 샘플 기업행동 사례와 한도 문서로 확인해야 한다.
- 백필 규모: 2019-01 이후 약 1,900거래일이므로 약 1,900회 호출이다.

## 3. 항목별 판정 (계획 5절 대비)

| 필요한 자료 | 판정 | 근거·차단 사유 |
| --- | --- | --- |
| ETF 원시 가격·거래대금 | 가능(백필 필요) | 2절 |
| 개장가 | 가능 | `TDD_OPNPRC` 전 행 존재. 장시작 직후 체결 대용으로의 적절성은 별도 검토 |
| 당시 종목군(폐지 포함) | 부분 가능 | 날짜별 응답으로 복원 가능해 보임. 폐지·청산 처리 자료는 없음 |
| 분배금·분할·병합 | **차단** | KRX ETF 응답 19개 필드에 분배금·기업행동 필드 없음. NAV와 종가도 분배금을 별도 가산하지 않음. 원천 미확정 |
| KOSPI 200 총수익지수 | **차단** | 현재 `KRX_API_KEY`로 `idx/kospi_dd_trd`·`idx/krx_dd_trd`·`idx/kosdaq_dd_trd`가 모두 401(Unauthorized). 지수 서비스는 별도 이용 신청이 필요한 것으로 보이며, 신청해도 총수익지수 제공 여부는 미확인 |
| 당시 유형·섹터 분류 | **차단** | API 필드는 `IDX_IND_NM`(추적지수명)뿐. `etf_master_kr`에도 분류 없음. 커버드콜·합성·혼합형 판정과 섹터 그룹 키의 공식 원천이 없음 |
| 데이터 가용 시각·정정 이력 | 미확인 | 응답에 공표·정정 시각 없음. 계획 5절의 보수적 지연 가정을 적용 |
| KRX 자료 공식 제공 시각 | 미확인 | 비공식 도구 설명에 "매일 오전 8시 갱신"이 있으나 공식 근거가 아니다. 공식 문서 확인 전에는 7절의 둘째 거래일 개장 체결 유지 |

공공데이터포털 금융위원회 증권상품시세정보(ETF 시세)는 무료이고 `basDt` 조건 조회를 지원한다고 확인했다. 분배금 필드 유무와 제공 시작일은 상세 페이지의 응답 표로 확인하지 못했다. 분배금 후보 원천(한국예탁결제원 SEIBro, 운용사 공시 등)은 아직 조사하지 않았고 가용성을 주장하지 않는다.

## 4. G1 차단 목록과 가능한 경로

| ID | 차단 | 해소안 | 필요 승인 |
| --- | --- | --- | --- |
| B1 | 분배금 이력 원천 없음 | 원천 후보 조사 후 이용 조건 확인 | 외부 원천 이용·비용이면 승인 |
| B2 | KOSPI 200 총수익지수 접근 불가 | KRX 지수 서비스 이용 신청(권한) 후 총수익지수 제공 여부 확인. 없으면 TR 대안 지수 또는 사전 선정 추종 ETF만으로 비교 | 권한·신청 승인 |
| B3 | 유형·섹터 분류 원천 없음 | 상품 분류 공식 원천 조사. 없으면 추적지수명 기반 분류표를 버전 관리하되 정식 게이트 근거 등급을 낮춤 | 원천 확정 시 판단 |
| B4 | 가격 소급 조정 여부·가용 시각 미확인 | 기업행동 사례 표본 대조(읽기 전용) | 없음 |

**가격수익률 기반 예비 연구**: B1~B3 없이도 KRX 백필(로컬 파일, DB 쓰기 없음)로 후보 규칙, 시점·체결·비용 로직, 회귀 테스트, 가격 기준 비교(추종 ETF 매수 후 보유 대비)를 구현·점검할 수 있다. 결과는 `분배금 미반영 예비 결과`로만 표시하며 G3 근거로 쓰지 않는다. 분배금을 무시하면 분배 수익이 큰 ETF가 과소평가되는 편향이 있다.

## 5. 4절 제안값 판단

- 벤치마크 확보 실패 시 "가격지수로 대체해 총수익 초과를 주장하지 않는다"는 계약이 이미 적용되는 상황이다(B2). 1차 벤치마크는 확정하지 않고 B2 결과에 따라 정한다.
- 비용 0.15%·유동성 10억 원·274관측일은 이 조사로 검증되지 않았다. 거래대금 분포 실측은 백필 후 ER-2에서 수행한다.
- 8.1절 구간은 가격 기준으로는 2019년 시작 백필로 충족 가능성이 있으나(약 7.8년), 총수익 기준은 B1이 풀려야 한다.

## 6. 공식 서비스 목록 확인 (2026-10-23, Q-40 A안 1차)

KRX Open API 포털 서비스 목록(`openapi.krx.co.kr`, 로그인 없이 공개)을 확인했다. 제공 대상 기간은 "2010년 이후"다.

- ETF 일별매매정보는 2010-01-04부터 제공한다. 2절 탐침 결과와 일치한다.
- 지수 서비스는 KRX·KOSPI·KOSDAQ 시리즈 **일별시세정보**(2010-01-04부터), 채권·파생상품지수, ESG 지수다. 총수익지수를 별도 서비스로 명시한 항목은 없다. KOSPI 시리즈 응답에 KOSPI 200 총수익(TR) 계열 지수가 포함되는지는 신청 후 응답으로만 확인할 수 있다.
- 분배금·기업행동·ETF 유형/섹터 분류를 제공하는 서비스는 목록에 없다. B1과 B3는 KRX Open API로 해소되지 않는다.
- 신청 절차: 포털 로그인 → API 인증키 신청에서 서비스별 이용 신청 → 승인. 로그인·약관 동의는 계정 소유자가 직접 해야 한다.

### 분배락 추정 가능성

종가 간 수익률과 `FLUC_RT`의 불일치가 1,336,038개 비교 중 9,011건(0.67%) 있었다. `기준가 = TDD_CLSPRC - CMPPREVDD_PRC`로 보면 전일 종가와 다른 날이 9,703건이고, 이 중 9,178건(94.6%)에서 기준가가 전일 종가보다 낮았다.

- 낮아진 폭의 전일 종가 대비 비율: 중앙값 0.39%, p90 1.59%, p99 3.48%, 최대 7.68%. 분배금으로 해석 가능한 범위다.
- 월별 건수는 4월(2,565)과 7월(1,239)에 집중하고 1·10·12월에도 많다. 분기·연간 분배 ETF의 분배락 시기와 방향이 일치한다.
- 525건은 기준가가 전일 종가보다 높았다. 분배락이 아닌 조정·반올림·기타 사유 후보이며 설명하지 못했다.
- 1,102개 코드에서 발생, 코드당 중앙값 5건.

**판정:** KRX 응답의 기준가 조정만으로 분배락 시점과 금액을 **추정**할 수 있는 정황이 강하다. 그러나 분배락이 아닌 기업행동(합병·분할·병합)과 구분되지 않고, 지급일·세금·재투자 시점은 알 수 없다. 공시(운용사·예탁결제원)와의 표본 대조 전에는 `추정 분배금` 등급으로만 사용하고 G1·G3의 정식 근거로 쓰지 않는다. 이 추정을 쓰면 B1을 **부분 완화**하지만 해소하지는 않는다.

### 영향

- 가격 기준 예비 연구는 즉시 진행 가능하다. 분배 추정을 더한 총수익 근사 비교는 예비 결과 안에서 별도 등급으로 병행할 수 있다.
- 4절 거래비용·유동성 제안값 검증과 후보 규칙 구현(ER-2)이 이 자료로 가능해졌다.
- 미해소: B2(총수익지수, 지수 서비스 401), B3(유형/섹터 분류), B4 중 가용 시각·정정 이력. 가격 소급 조정 여부는 급변동 샘플에서 분할이 보이지 않아 영향이 작아 보이나 정식 확인은 미완료다.

## 8. KOSPI 시리즈 일별시세정보 승인 후 재탐침 (2026-10-23, Q-40)

사용자가 KOSPI 시리즈 일별시세정보 이용 승인을 확인했고, 같은 `KRX_API_KEY`로 `idx/kospi_dd_trd`가 200을 반환했다. `idx/krx_dd_trd`(KRX 시리즈)는 여전히 401이다.

- 응답 12개 필드: `BAS_DD`, `IDX_CLSS`, `IDX_NM`, `CLSPRC_IDX`, `CMPPREVDD_IDX`, `FLUC_RT`, `OPNPRC_IDX`, `HGPRC_IDX`, `LWPRC_IDX`, `ACC_TRDVOL`, `ACC_TRDVAL`, `MKTCAP`. 2026-09-22 기준 54개 지수, 2019-01-02는 48개, 2010-01-04는 41개 지수가 조회된다.
- `코스피 200`은 **가격지수**다. 총수익 지수(TR)는 없다. 이름에 TR 계열이 있는 것은 `코스피 200 25/50 NTR 지수`·`25/50 NTR USD 지수`뿐이며 이는 비중 상한 변형 지수라 표준 벤치마크로 쓰지 않는다.
- 업종 지수(예: `코스피 200 정보기술`, `코스피 200 헬스케어`, 업종별 코스피 지수)는 있으나 ETF와의 연결 정보는 아니다. B3의 해소 자료가 아니다.

**판정:** B2는 KRX Open API로 해소되지 않는다. 4절 계약대로 가격지수만 확보한 상태에서는 총수익 초과를 주장하지 않고 G3를 보류한다. 대안은 (a) 사전 선정한 KOSPI 200 추종 ETF의 `가격수익률 + 추정 분배금` 근사 총수익을 벤치마크로 쓰는 예비 비교, (b) 별도 원천(KRX 정보데이터시스템·유료 데이터)에서 TR 지수를 확보, (c) 가격지수 비교로 한정이다.
