# ETF 신호 MVP — KR 누락일 보충 구현 기록

> 작업일: 2026-09-22 KST
> 상태: 코드·timer 원본 구현 및 로컬 검증 완료. 운영 설치본 갱신·첫 자동 E2E는 미실시.

## 결정 및 범위

- 운영 PC 가동 시간은 평일 09:00~18:00 KST다. US까지 무손실을 필수로 보장하는 요구는 철회하고 KR 누락일 보충을 먼저 구현한다.
- KR timer 원본은 평일 09:30 KST로 변경했다. 늦게 기동할 때에도 09:00~17:00 사이에서만 KR workflow를 dispatch한다. GitHub workflow는 입력 없이 실행되면 2026-09-22부터 전일의 모든 평일을 오래된 순서로 점검한다. 명시적 `market_date` 입력 수동 실행은 기존 KR daily 경로를 유지한다.
- 완료된 KRX 일별 데이터는 재수집하지 않는다. 비거래로 기록된 평일은 KRX의 일시적 빈 응답을 대비해 다음 실행에서도 재조회한다. 수집·검증이 실패한 날짜에서 중단하고 이후 날짜는 다음 실행으로 넘긴다.
- 보충 경로는 기준일별 신호를 계산하고, 앞선 거래일이 뒤늦게 채워지면 뒤 날짜의 5·20거래일 신호도 다시 계산한다. 동일 실행의 낡은 신호 유형별 행은 새 결과에 맞춰 제거하고 다시 적재한다. 모든 신호 유형 저장 후 완료 마커를 남기며, 실패 시 다음 실행이 재시도한다.
- 보충 경로는 Kiwoom 과거 마스터와 당시 신규 상장 관측을 복원하지 않으며 운영 Telegram을 자동 발송하지 않는다. 이 경계에서는 KR 원천 KRX 일별 데이터·파생 신호 보충만 구현했다. 과거 관측일은 M6의 완전 거래일로 자동 집계하지 않는다.

## 검증 및 배포 대기

- 날짜 지정 KR 신호 계산 회귀 테스트, 누락일 순서·실패 중단·재계산·근무시간·낡은 신호 삭제 테스트 추가.
- `npm test`: 29개 파일·90개 테스트 통과. `npx tsc --noEmit`, `npm run lint`, `npm run build`, `npm run continuity:check`, `git diff --check` 통과.
- Linear KOR-58에 구현 범위·운영 검증 대기·관측 0/20을 기록했다. OpenViking 재개 메모리에도 US 무손실 필수 철회와 KR 보충 경계를 저장했다.
- 운영 timer 설치본(`~/.config/systemd/user/`)과 독립 dispatch 스크립트 설치본(`~/.local/lib/etf-ops/`)은 아직 변경하지 않았다. 첫 자동 실행 및 Supabase 운영 저장 결과는 미검증이다. 운영 설치·실측 뒤에만 Linear KOR-58의 0/20 시작 게이트를 통과로 바꾼다.
- US timer는 현행 07:30을 유지한다. 근무시간 재편은 KR 보충 E2E 이후 별도 작업으로 남긴다.

## 남은 위험

- KRX가 과거 영업일에 빈 응답을 반복하면 휴장인지 공급자 장애인지 자동으로 구분할 수 없다. `NON_TRADING` 평일은 재조회하지만 수동 확인이 필요할 수 있다.
- 신호 행 교체는 여러 Supabase 요청으로 이뤄져 원자적 트랜잭션이 아니다. 중간 실패 시 완료 마커가 없으므로 다음 실행에서 재시도하지만, 그 사이 대시보드의 일부 행이 일시적으로 비어 보일 수 있다.
- 운영 PC가 근무시간에 켜지지 않으면 복구는 다음 근무시간까지 지연된다. 보충 경로는 당시의 Kiwoom·Telegram 상태를 재현하지 못한다.
