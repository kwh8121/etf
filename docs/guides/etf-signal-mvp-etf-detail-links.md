# Telegram ETF 종목별 상세 링크

2026-10-16 사용자 요청으로 키움 링크 검증 대기를 끝내고 공개 웹 상세 페이지를 연결했다. 앞서 제안한 국내 네이버·미국 Yahoo Finance 조합을 적용한다. 미국 네이버 종목 주소에 필요한 거래소 구분을 기존 티커만으로 확정하지 못했으므로 임의 접미사를 만들지 않는다.

| 보고 시장 | ETF 이름 클릭 시 목적지 | 예시 |
| --- | --- | --- |
| KR | 네이버 증권 종목 상세 | [KODEX 200](https://m.stock.naver.com/domestic/stock/069500/total) |
| US | Yahoo Finance 종목 상세 | [VOO](https://finance.yahoo.com/quote/VOO/) |

현재 순위와 랭크아웃의 ETF 이름에 같은 링크를 붙인다. 기존 종목코드·티커로 주소만 구성하며 상세 데이터 수집·별도 매핑·DB 변경·추가 환경 변수는 없다. 배포된 코드로 새로 생성하는 보고부터 적용되고 이미 받은 Telegram 메시지는 바뀌지 않는다. 보고 헤더의 자체 웹 열람 주소도 유지한다.

## 표시와 오류 경계

- 국내 코드는 대문자 영숫자 6자리, 미국 티커는 대문자로 시작하는 최대 20자리 영숫자·마침표·하이픈만 링크로 만든다. 형식에 맞지 않으면 이름만 표시한다. 형식 통과가 외부 사이트의 모든 종목 지원을 보증하지는 않는다.
- 이름·메타데이터의 HTML 특수문자를 escape하고 이름의 줄바꿈을 공백으로 바꾼다. KR·US 종목 보고에만 Telegram HTML 모드를 명시한다. 링크 미리보기는 비활성화한다.
- 긴 보고는 완전한 행 단위로 분할한다. 헤더와 단일 HTML 행이 한 메시지 제한을 넘으면 발송 전에 오류로 종료해 링크를 중간에서 자르지 않는다.
- 외부 서비스의 화면·광고·지역 제한·종목 지원 변경은 이 저장소에서 제어하지 않는다. 로그인이나 증권 앱 설치 없이 종목 상세가 열리는 대표 주소를 검증했으나 모든 종목·운영체제의 동작을 보증하지 않는다.

## 검증 범위

Chromium에서 네이버 `069500`과 Yahoo `VOO`를 각각 360×800·1440×900 화면으로 열어 종목명이 일치함을 확인했다. 네이버 문서 폭은 각각 360·1440px였다. Yahoo 문서 폭은 364·1440px로 작은 화면에서 4px의 가로 넘침이 있었다. 이는 브라우저 화면 폭 검사이며 실제 iOS·Android·Telegram 내장 브라우저 클릭 검증은 아니다.

단위·스크립트 통합 테스트는 URL 구성, 특수문자, 잘못된 코드, 현재·랭크아웃 양쪽 링크, HTML 발송 옵션, 일반 상태 알림의 기본 텍스트 처리, 분할 시 링크 보존과 단일 행 초과를 확인한다. Telegram API는 mock으로 대체하며 이 작업에서 시험 발송·운영 수동 실행은 하지 않는다.
