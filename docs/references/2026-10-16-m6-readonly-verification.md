## 범위와 판정 원칙

사용자 `확인가능한 부분 확인해줘.`에 따라 현재 저장 데이터·보관 원천의 재계산 대조와 기존 자동 실행·보고 증거를 확인한다. 운영 DB 정정·과거 보고 재발송·새 시세 API 호출·timer 변경은 포함하지 않는다. 이 문서는 점검 근거이며 누적 상태의 정본은 `docs/plans/NEXT.md` Q-08이다.

검증 통과는 현재 코드와 저장 원천을 사용한 재계산 일치를 뜻한다. 같은 계산기를 사용하는 대조이므로 계산 공식의 독립적인 수학적 검증이나 원천 공급자의 사실 정확성 보증으로 확대하지 않는다. 사후 정정된 DB와 당시 보고된 내용도 구분한다.

## 수신 확인과 남은 공백

사용자는 오늘 링크 테스트 재전송 뒤 `성공적으로 수신했습니다.`라고 확인했다. KR 4개·US 2개 재전송의 수신 증거로 기록한다. 정규 자동 발송 원문 전체의 내용 일치·헤더 날짜·자체 웹 화면의 360px 표시까지 확인한 것으로 확대하지 않는다. 시험 재전송은 별도 거래일로 추가 집계하지 않는다.

따라서 지금 확정할 수 있는 것은 현재 DB 기준 최근 3일의 재계산 일치와 10-15의 정상 자동 운영 기술 후보 1일이다. 기존 운영 관측 9/20은 당시 기록으로 보존하며 콘텐츠 정확성 기준 9일로 사용하지 않는다. 10-13·10-14를 사후 정정으로 자동 승격하거나, 10-15를 아직 확인하지 않은 화면 조건까지 충족한 최종 관측일로 확정하지 않는다. M6 종료·Q-09 착수·기존 예상 종료일 확정도 하지 않는다.
